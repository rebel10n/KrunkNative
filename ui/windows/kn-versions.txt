 == KRUNKER BOX OFFICE ==
 - Krunker Box Office's own changelog: the What's New window (showWindow(35)) and the Changelog link
 - read by client/src/ui/v10_news.c, in Krunker's docs/versions.txt format: "== UPDATE x.y.z ==" starts an update,
 - "* Name" a group, "- text" a change, "@url" an image; the first update is the current version

 == UPDATE 1.2.0 ==
 * Krunker v10.0.2
 - The v10 menu: Guide, What's New, Community & Events, Ranked and Turf Wars
 - v10 gameplay: Boulder and Compressor, posed hitboxes, new modes and ranked rules
 - Ranked seasons with the v10 rank icons, clan Turf Wars with daily territory
 * Economy
 - Gifting, the market, quick sell, the Black Market and trading
 * Gameplay
 - Third person camera over the shoulder
 - Tool Gun, Physics Gun and building tools in the Object Manager (F1)
 - Voice chat built in, spectators heard
 - Nuke for every player, with flash and shake on detonation
 - Bots fill public lobbies until humans arrive
 * Fixes
 - Pointer lock: one owner for the cursor, keys back to the game
 - Idle kick counts held keys, slow turns, shots and damage as activity
 - Death cam no longer drifts into the void

 == UPDATE 1.1.0 ==
