 == KRUNKER BOX OFFICE ==
 - Krunker Box Office's own changelog: the What's New window (showWindow(35)) and the Changelog link
 - read by client/src/ui/v10_news.c, in Krunker's docs/versions.txt format: "== UPDATE x.y.z ==" starts an update,
 - "* Name" a group, "- text" a change, "@url" an image; the first update is the current version

 == UPDATE 10.0.5 ==
 * General
 - Added the 71 November spin items to the item list (they join the spins when Krunker's November spins start)
 - Added the 4 Ametwista Twitch drops with their custom shader, and the Deathweaver item
 - Added a Register reminder for guests, as on Krunker
 * Notifications
 - The Notifications panel now matches Krunker's
 - Follows and messages no longer pop up desktop notifications; they stay in the Inbox and the chat
 - Quick-sell, List and Buy multiple results show in their own windows, as on Krunker
 * Editor
 - Added a Collision Size field for custom assets, with Fit Collision To Model
 - Added Convert to Collision Mesh to the right-click menu
 - Collision triangles on imported maps can now be selected, moved and deleted
 - Fixed map collision being lost when importing and exporting maps

 == UPDATE 10.0.4 ==
 * Candy Heist
 - Added the Candy Heist map and mode: collect candy, bank it at the Cauldron and avoid the Hollowmen
 - The Hollowman's Staff counts the candy you bank
 * General
 - Added a map loading screen
 - Reduced stutter when a match starts
 - Added an Interact button on mobile
 - Added a Privacy & Age section to profile Settings
 - Matches played alone now end with ENDED instead of DEFEAT
 - Chat-restricted players can now vote to forfeit
 - Item drops can be equipped without relogging
 - Counter skins now show their counts, and skins with custom shaders now render
 - Fixed some Shotgun skins not showing in item previews
 - Improved the size of waist items in item previews
 * Store
 - Buy KR, bundles, premium and battle pass tiers with card (Xsolla or Stripe), and gift them
 * Inventory & Market
 - Added item locks to protect items from quick-sell, listing and trades
 - Added Select mode to the inventory to quick-sell many items at once, with Keep options
 - Added Select mode to the market inventory to list many items at once
 - Added Buy multiple to listings
 * Raids
 - Raid bosses drop their rewards, with double drops on double drop weekends
 * KrunkScript & Editor
 - Added AI Rarity Chances and doubleRaidDrops to GAME.CONFIG.getMatch()
 - Studios can now publish, unpublish and edit currencies
 - Setting a player's score now only counts the difference toward score challenges
 - Improved the third-person arm for player.pose.holdL
