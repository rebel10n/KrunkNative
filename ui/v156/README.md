# ui/v156/ — the Krunker v1.5.6 menu page

Krunker v1.5.6's own menu page, the menu of Settings > General "Game version" = "v1.5.6 (menu
only, plays v7.1.4)" (`client/src/ruleset_page_v156.c`, `doc/v7/decisions.md`). It is a menu
page only: v1.5.6's gameplay is not ported, so games under it play Krunker v7.1.4 (offline and
quick join; online the server's version) and the client says so when it is picked and at the
first game. Native only: the web build serves `ui/` (dist/web leaves this directory out).

Everything here except this file is generated by `make ui-import-v156`
(`python3 -I tools/ui-import/import.py --ui ui --ref v156`, `tools/ui-import/v156_page.py`);
regenerate rather than edit.

## Provenance

From `/home/user/jails/kru/src/Krunker_v1.5.6/public` (never its game content):

- `index.html`: v1.5.6's `index.html` with every `<script>` (adsbygoogle, the CDN tags, hook.js,
  game.js, the libs, reCAPTCHA), comments (the freestar ad block), the favicon link, the
  description / keywords / Accept-Ranges metas and the `.g-recaptcha` placeholder removed;
  `?build=` / `&v=` stripped; `/css/...` and `./...` URLs made relative; external `<a href>`s
  neutralised (`data-ext-href`); our hooks as in `ui/index.html` (`<canvas id="canvas">`,
  `css/krunknative.css` + `css/hud.css`, `js/kn-shim.js` + `js/loader.js`), plus
  `css/kn-v156.css` and a `#popupHolder > #popupBack + #confPop` host for `ui_confirm()`
  (v1.5.6 used the browser's `confirm()`).
- `css/main.css`, `css/material_icons.css`: unchanged apart from the URL rewriting.
- `css/kn-v156.css`: Krunker v3.1.1's own `#popupHolder` / `#popupBack` / `#confPop` /
  `#confirmBtn` / `#declineBtn` rules, extracted from v3.1.1's `css/main.css` at import time.
- Fonts: `css/fonts/font2.ttf` (GameFont), `css/fonts/micon.woff2` (Material Icons) and its
  `material-icons.ttf` (same ligature table as v7's, so the engine's header is shared).
- Images: every local file the page and its stylesheets reference (`img/`, the five HUD
  `textures/` files). v1.5.6 itself 404s on `css/fonts/header.ttf` (HeaderFont),
  `img/lock-icon-{black,white}.svg` and `img/social-buttons/fandom-*.png`; they stay missing.
- `windows/versions.txt`: v1.5.6's `docs/versions.txt` (the Changelog).
- Our glue files (`css/krunknative.css`, `css/hud.css`, `css/devconsole.css`,
  `css/ranked-kn.css`, `js/kn-shim.js`, `js/loader.js`): copies of `ui/`'s.

## Known gaps

v1.5.6 has no window templates (its `windows[n].gen()` built them at run time and nothing captured
them): every window, Settings included, is `ui/windows/`'s v7.1.4 markup, which v1.5.6's
stylesheet does not style. The C UI drives the page through v7.1.4's element ids; where v1.5.6's
differ, that part stays empty or static (the logo, the in-game health bar and leaderboard, the
killcard shows outside a death). See the v1.5.6 entry in `doc/v7/decisions.md`.
