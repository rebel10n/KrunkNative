# Krunker v10.0.2 in-game references (offline v10 sandbox)

Captured from the OFFLINE v10 sandbox: the pinned v10.0.2 client (`~/jails/kru/src/Krunker_v10.0.3/deob/v10.0.2/game.js`) on the
mirrored krunker.io page in sandboxed headless Chromium, with nothing leaving the machine (fresh
profile deleted afterwards, the proxy a closed port, every krunker.io request answered from the local
mirror, no WebSocket, no login). Made with `node tools/uidiff/capture-v10.js` (its header lists the
sandbox rules and the determinism steps). The user approved running the v10 client sandboxed for UI
capture on 2026-10-13.

The sandbox is v10's own in-browser game (localStorage `custMap`: v7.1.4's Kanji, narrowed to one
mode), entered through v10's real pointer-lock path. The 3D canvas is transparent over flat black,
the timer is pinned to 03:45 and CSS animations are paused at 800 ms. Each capture is `<name>.png`,
`<name>.html.gz` (the DOM afterwards) and `<name>.rects.json` (element rects for the uidiff regions).

| Capture | State |
|---|---|
| ingame-plain / -scoped / -reloading | spawned (FFA), aiming, three shots + R |
| ingame-scoreboard | Tab held |
| ingame-chat-open / -chat-lines | Enter + `gg`; 12 spawnBot / clearBots lines |
| ingame-killfeed | a kill on a sandbox bot (kill feed under the always-shown leaderboard) |
| ingame-death / -death-self | killed by the bot / with no killer |
| ingame-spectate | spectating (setSpect, then the server's spectator START_GAME) |
| ingame-minimap | `toggleMinimap(true)` (v10's showMinimap is off by default) |
| ingame-mode-point / -mode-ctf | Hardpoint / CTF on Kanji |
| ingame-endscreen / -endscreen-late | the end animation; the results 7 s later (guest) |
| ingame-pause-esc | ESC in game: the sandbox's menu (its chrome trimmed by v10's sandbox code) |

Known capture artifacts: the minimap has no map image (Kanji's mmId image is not in the mirror); the
spectate list has no player cards; the ESC menu shows the sandbox's trimmed menu, not the connected one.
The uidiff scenarios are `tools/uidiff/scenarios/v10/ingame-*.json` (generated by
`tools/uidiff/gen_v10_ingame.py`); the native e2e is `server/tests/v10_hud_e2e.py`.
